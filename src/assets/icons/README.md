# Icons Directory

Place your SVG icon files here for use in the components.

## Required Icons

The following icons are referenced in the default example data:

- `bank.svg` - Credit institutions icon
- `payment.svg` - Payment institutions icon
- `emoney.svg` - Electronic money institutions icon
- `investment.svg` - Investment management companies icon
- `register.svg` - Credit register icon
- `market.svg` - Financial instruments market icon

## Icon Guidelines

- Use SVG format for scalability
- Keep icons simple and consistent in style
- Recommended size: 24x24px or 48x48px
- Use monochrome or simple color schemes
- Optimize SVGs before adding them
